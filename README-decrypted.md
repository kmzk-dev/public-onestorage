# ONESTORAGE ローカル復号ツール
ONESTORAGEサーバーが万が一利用できなくなった場合に、あなたが保存した暗号化ファイルを安全に手元のコンピュータで復号（元の状態に戻す）するためのツールを提供します。

ツールは本リポジトリの`/decrypt_tool`にまとまっています。

## 必要なもの
1.  **暗号化されたファイル**: サーバーからダウンロードしたファイル、またはそのバックアップ。
2.  **あなたのメールアドレス**: ONESTORAGEに登録したメールアドレス。これが復号キーになります。

あなたの状況に合わせて、2つのツールのうちどちらかを選んでお使いください。

### Webブラウザ版 `decrypt_tool/decrypt.html`
ファイルを1つずつ手軽に復号したい場合に最適です。特別なソフトは不要で、Google ChromeなどのWebブラウザさえあれば利用できます。

#### 使い方
1.  `decrypt.html` ファイルをダブルクリックして、Webブラウザで開きます。
2.  画面の指示に従い、「メールアドレス」と「暗号化されたファイル」を1つ選択します。
3.  「復号してダウンロード」ボタンをクリックします。
4.  処理が完了すると、元のファイル名に `_decrypt` が付いたファイルが自動的にダウンロードされます。

> **安全性について**
> このツールは、すべての処理をあなたのコンピュータ内（ブラウザ上）で完結させます。ファイルやメールアドレスがインターネット上に送信されることは一切ありません。

### Windowsアプリ版 `decrypt_tool/decrypt.zip`
フォルダ内のファイルをまとめて一度に復号したい場合に最適です。フォルダには暗号化されたファイルのみを格納するようにしてください。フォルダや暗号化されていないファイルを混在させないでください。

#### 使い方
1.  配布されたZIPファイルを解凍してください。
2.  回答したフォルダの中にある `decrypt.exe` という名前のアプリケーションをダブルクリックして起動します。
    * もしセキュリティ警告が表示された場合は、「詳細情報」→「実行」を選択してください。
    * **注意: フォルダ内の他のファイルを移動したり削除したりしないでください。**
3.  アプリが起動したら、ONESTORAGEに登録したメールアドレスを入力します。
4.  `復号元フォルダ`ボタンを押し、暗号化されたファイルが入っているフォルダを選択します。
5.  `保存先フォルダ`ボタンを押し、復号したファイルを保存したい場所（空のフォルダを推奨）を選択します。
6.  `復号を開始`ボタンをクリックすると、フォルダ内のファイルが自動的にすべて処理されます。
7.  処理が完了するとメッセージが表示されます。詳細はアプリ内のログで確認できます。

### Pythonスクリプト版 `decrypt.py`

**開発者や、ご自身のPCにPython環境がある方向けです。**

`exe`ファイルを実行する代わりに、Pythonスクリプトを直接実行してツールを起動します。

#### 使い方
1.  **ライブラリのインストール:**
    `decrypt.py` の実行には、暗号化処理のための `pycryptodome` ライブラリが必要です。コマンドプロンプトやターミナルを開き、以下のコマンドを実行してインストールしてください。
    ```bash
    pip install pycryptodome
    ```

2.  **スクリプトの実行:**
    ライブラリのインストール後、`decrypt.py` があるフォルダで以下のコマンドを実行すると、Windowsアプリ版と同じツールが起動します。
    ```bash
    python decrypt.py
    ```
    起動後の使い方は、上記のWindowsアプリと同じです。

## トラブルシューティング

#### 復号に失敗しました」と表示されます。
**A.** ほとんどの場合、入力したメールアドレスが間違っています。ONESTORAGEに登録したメールアドレスと完全に一致しているか、大文字・小文字、前後の空白などを含めて再度ご確認ください。それでも失敗する場合、ファイルが破損している可能性があります。

#### Windowsアプリ版が起動しません。
**A.** ウイルス対策ソフトが誤って作動をブロックしている可能性があります。アプリを右クリックして「管理者として実行」を試すか、一時的にウイルス対策ソフトの設定をご確認ください。また、必ずフォルダの中から `.exe` ファイルを実行しているか確認してください。
