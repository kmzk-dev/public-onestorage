# ONE STORAGE

## コンセプト
ONE STORAGEは、レンタルサーバーに割り当てられた余剰なストレージリソースを最大限に活用する、**軽量・高速・セキュア**に特化したセルフホスティング型ファイルストレージです。
その目的は **「個人が本当に秘密にしたい、誰にも見られたくないセンシティブな情報」** を、**安価・軽量・安定**して保管することにあります。

国内の低スペックかつ安価なレンタルサーバーでも軽快かつ安全に稼働するよう設計されています。

---

## ユースケース
- **レンタルサーバーの余剰容量活用:** ホームページ運営等で余っている大容量サーバー領域を、自分専用のプライベートオンラインストレージとして有効活用。
- **プライバシー重視のデータ隔離:** 大手パブリッククラウドの**AI学習・自動監査・外部検閲**からデータを完全に切り離し、自分だけの暗号化空間に隔離保管。
- **クラウド運用コストの削減:** NextCloud等の高機能・高負荷なストレージのために契約していた高額サーバープランを、最安プランに切り替えてコスト最適化。

## 主な特徴と動作要件

| 特徴 | 説明 | メリット |
| :--- | :--- | :--- |
| **PHP8.0+ ネイティブ** | 外部依存パッケージなし（Composer不要） | 導入制限のある共用レンタルサーバーでもそのまま動作 |
| **SQLite 高速キャッシュ** | データベースサーバー不要、軽量SQLiteファイル（`.storage.db`）で高速索引 | 高速インクリメンタル検索・高速一覧表示を外部DB設定なしで実現 |
| **常時ストリーム暗号化** | AES-256-CBCによる保存時ストリーム暗号化 | サーバー管理会社や第三者による物理ディスク直接閲覧からデータを完全保護 |
| **チャンク分割アップロード** | ファイルを小ブロックに分割して非同期転送 | サーバーのファイルアップロード上限や実行時間制限（`max_execution_time`）を回避 |
| **ワンファイル導入** | `installer.php` 1ファイルをアップロードするだけで即時セットアップ | FTP等での煩雑なファイル展開・権限設定作業が不要 |

### サーバー要件
- **PHP 8.0 以上**
- **PDO SQLite 拡張**（標準で有効なサーバーがほとんどです）
- **ZipArchive 拡張**
- **cURL 拡張** または `allow_url_fopen = On`
- 公開ディレクトリへの書き込み権限

## 主要機能

| 機能名 | 説明 |
| :--- | :--- |
| **🔄 管理画面セルフアップデータ** | 管理画面（`admin.php`）からワンクリックで新バージョンを確認・更新。設定やデータを完全保護したまま自動アップデート。 |
| **⚡ ワンファイルインストーラー** | `installer.php` を配置してアクセスするだけで、最新リリースの自動ダウンロード・解凍・環境チェックを実行。 |
| **🔒 常時AES-256-CBC暗号化** | アップロード時に自動暗号化。管理者のメールアドレスから派生した鍵を使用し、手元の復号ツールで確実に復元可能。 |
| **🔑 二要素認証（MFA / TOTP）** | Google Authenticatorなどの認証アプリによるTOTP二段階認証に対応。初期設定時および管理画面から有効/無効の切り替えが可能。 |
| **📊 容量管理 & 残容量プログレス** | 管理画面から最大ストレージ容量（GB）を設定可能。ナビゲーションバーに利用量・残容量をリアルタイム表示し、上限超過時のアップロードを自動ブロック。 |
| **📁 フォルダ200件上限 & バッジ表示** | フォルダごとのアイテム数を最大200件に制限。一覧ヘッダーに `(X / 200)` バッジを表示し、大量ファイルによるサーバー過負荷を未然に防止。 |
| **🔍 高速ファイル名検索** | SQLiteインデックスを活用したインクリメンタル検索。ヘッダーの検索アイコンからすぐに呼び出せ、検索結果から直接プレビューや親フォルダへ移動可能。 |
| **🔗 SHARE BOX（安全な共有リンク）** | 外部共有用の専用リンクを作成可能。有効期限・パスワード・ダウンロード上限回数を設定でき、不要になったら即時無効化。 |
| **📥 INBOX（安全な一時保管所）** | ディレクトリ階層と隔絶された一時保管用フォルダ。誤ってフォルダごと削除してしまうリスクを防ぐ「とりあえず保存」領域。 |
| **⭐ スター（お気に入り）機能** | 頻繁に使う重要ファイルやフォルダに★マークを付け、専用ビューからワンクリックでアクセス。 |
| **🖼️ プレビュー機能** | 画像（JPG, PNG, GIF, WebP等）およびPDFファイルをダウンロードせずにブラウザ上で高速プレビュー表示。 |
| **📂 階層型ファイル移動** | 現在地またはルートから目的のフォルダまで潜る（ドリルダウン）直感的なモーダル操作で、深い階層への移動もスムーズ。 |
| **🛡️ 二重セキュリティ保護** | `.htaccess` による直接アクセス遮断に加え、データ・設定ディレクトリ内にアクセス防止用 `index.html` を自動配置。管理画面で自己診断テストも可能。 |

## インストール手順

ONE STORAGEは、非エンジニアの方でも安全かつ簡単に導入できる設計となっています。

### ⚡ 方法1: ワンファイルインストール（推奨）

**PHPファイルを1つアップロードするだけで自動インストールが完了します。**

1. [Releases](https://github.com/kmzk-dev/public-onestorage/releases/latest) ページから **`installer.php`** をダウンロードします。
2. `installer.php` をレンタルサーバーの**公開ディレクトリ（`public_html` や `htdocs` 等）**にアップロードします。
3. Webブラウザで `https://あなたのドメイン/installer.php` にアクセスします。
4. 画面の指示に従って「環境チェック」「最新バージョンの自動ダウンロード」「ファイル展開」を実行します。
5. 展開完了後、自動的に初期セットアップ画面（`setting.php`）が開きます。
   - 管理者メールアドレス・パスワードの登録
   - 二要素認証（MFA）の設定（QRコードを認証アプリでスキャン）
   - 初期ストレージ容量上限の設定
6. ⚠️ **セットアップ完了後は、セキュリティのため必ずサーバー上の `installer.php` を削除してください。**

---

### 📦 方法2: 手動インストール（ZIP配置）

レンタルサーバーのファイルマネージャーやFTPソフトを利用して手動で配置する方法です。

1. [Releases](https://github.com/kmzk-dev/public-onestorage/releases/latest) ページから最新の **`onestorage-vX.X.X.zip`** をダウンロードし、PC上で解凍します。
2. 解凍したファイル群を、レンタルサーバーの公開ディレクトリ直下にアップロードします。
   ```text
   公開ディレクトリ/
   ├── functions/       # バックエンド処理ロジック
   ├── static/          # CSS, JS, UIコンポーネント, 画像
   ├── .htaccess        # アクセス制限設定
   ├── index.php        # メインエントリポイント
   ├── login.php        # ログイン画面
   ├── mfa_login.php    # MFA認証画面
   ├── logout.php       # ログアウト処理
   ├── admin.php        # 管理者設定画面
   ├── setting.php      # 初期セットアップ画面
   ├── share.php        # 共有ファイルアクセス画面
   └── path.php         # パス解決ヘルパー
   ```
3. Webブラウザでアップロード先のURL（`https://あなたのドメイン/`）にアクセスします。
4. 自動的に初期セットアップ画面（`setting.php`）に誘導されますので、画面の指示に従って設定を完了させてください。

## アップデート手順

ONE STORAGE は、既存の設定（`config/`）や暗号化データ領域（`data*` / `share*`）、データベース（`.storage.db`）を**100%保護したまま**最新版へ更新できます。

### 🔄 方法1: 管理画面からの直接アップデート（推奨）

すでに ONE STORAGE が導入されている場合、ブラウザからワンクリックでアップデートが完了します。

1. 管理画面（`https://あなたのドメイン/admin.php`）にログインします。
2. **「バージョン情報」** セクションの **「アップデートを確認」** ボタンをクリックします。
3. 新しいバージョンが検出された場合、更新先バージョンを選択し **「このバージョンにアップデート」** をクリックします。
4. 自動的に最新パッケージのダウンロード・展開・安全なファイル上書きが行われ、完了後に画面が自動リロードされます。

> [!TIP]
> アップデート処理中もセッション情報は維持され、既存のログインアカウントや設定情報、アップロード済みデータが失われることはありません。

### ⚡ 方法2: `installer.php` を用いたアップデート

管理画面にアクセスできない場合や手動で実行したい場合：

1. [Releases](https://github.com/kmzk-dev/public-onestorage/releases/latest) ページから最新の **`installer.php`** をダウンロードします。
2. 公開ディレクトリにアップロードし、ブラウザで `https://あなたのドメイン/installer.php` にアクセスします。
3. 既存の ONE STORAGE が自動検出され、**「アップデートモード」** として安全に更新が適用されます。
4. 更新完了後は、セキュリティのため `installer.php` を削除してください。

## セキュリティとデータ保護

ONE STORAGE は、多層防御と常時暗号化によって利用者のプライバシーを保護します。

- **常時ストリーム暗号化 (AES-256-CBC):** ファイルは管理者メールアドレスから生成された鍵で保存時に暗号化されます。
- **万が一のローカル復旧保証:** サーバーが停止した場合でも、メールアドレスと [`README-decrypted.md`](README-decrypted.md) に記載のローカル復号ツール（ブラウザ・EXE・Python）で手元で確実に復号できます。
- **詳細なセキュリティモデル:** 脅威モデル、二要素認証、多重アクセス防御、保存データガイドライン等の詳細は **[README-security.md](README-security.md)** をご覧ください。
